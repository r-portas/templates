# react

A blank minimal React application.

## Getting Started

```bash
# Install dependencies
bun install

# Start the development server
bun dev

# Update dependencies to the latest versions
bun run update
```

## Keeping in sync with the template

This project was created from the [`react`](https://github.com/r-portas/templates/tree/main/templates/react)
template. Run the `sync-template` Claude Code skill (`/sync-template`) to pull in changes made to
the template since this project was created.
